เว็บสำหรับครีเอเตอร์ Affiliate ที่ทำคลิป TikTok ขายสินค้า PN Infinity — หน้าเดียว ใช้บนมือถือเป็นหลัก ไม่มี build step

| แท็บ | มีอะไร |
|---|---|
| แคมเปญ | ภาพปก · ตัวเลขสรุป · ทำไมต้องมีเครื่องผสมคลิป · รายละเอียดแคมเปญ · สิทธิประโยชน์ · สินค้าในแคมเปญ · ข้อตกลง · กติกาฟุตเทจแบรนด์ · ช่องทางติดต่อ |
| สินค้า | บรีฟสินค้าแยกหมวด — ประเภท · SKU · เลข อย. · จุดขายที่พูดได้ · คำห้ามพูด · ระดับความเสี่ยง · ปุ่มคัดลอกจุดขาย |
| กฎ | ตัวตรวจคำเสี่ยง (ไฮไลต์ในข้อความ + คำแนะนำ · กรองตามประเภทสินค้าได้) · คำเสี่ยง → เปลี่ยนเป็น · กติกาการถ่ายและโพสต์ · เช็กลิสต์ก่อนโพสต์ (จำค่าไว้ในเครื่อง) |
| ไอเดีย | เครื่องผสมคลิป สุ่ม ไอเดีย × Hook × รูปแบบตัดต่อ × คำปิดท้าย (Hook จับคู่ตามหมวดสินค้า) · คัดลอกเป็นบรีฟ · คลังไอเดียกรองตามสินค้า |
| ตัดต่อ | คำปิดท้ายชวนกดตะกร้า (แตะเพื่อคัดลอก) · รูปแบบตัดต่อพร้อมจังหวะและความยาว |

ลิงก์ตรงเข้าแต่ละแท็บได้ เช่น `#prod/probiova` (เปิดบรีฟ Probiova) · `#idea/hayeon` (ไอเดียของ Hayeon)

## แก้ข้อมูล

- **`js/data.js`** — แบรนด์ · แคมเปญ · สินค้า (ทีมแก้ไฟล์นี้เป็นหลัก)
  ค่าไหนยังไม่รู้ให้ใส่ `null` หน้าเว็บจะขึ้นป้าย **รอข้อมูล** เอง — ห้ามเดาเลข อย. หรือจุดขาย
  - `campaign.footageReady: false` = ทีมยังไม่แจกฟุตเทจแบรนด์ → เครื่องผสมคลิปไม่สุ่มไอเดีย/รูปแบบที่ต้องใช้ฟุตเทจ (ในคลังยังเห็น พร้อมป้าย "รอทีมแจกฟุตเทจ") — แจกแล้วเปลี่ยนเป็น `true`
  - ประเภทสินค้าอ้างอิงตารางรหัสสินค้าของระบบคีย์ออเดอร์ (U4: เซรั่มนาโน · สบู่นาโน · ฮายองคอลลาเจน · UN1: ครีม/สบู่พลูคาว) — MerryCollagen กับ venorra ยังรอยืนยัน
- **`js/library.js`** — ไอเดีย · Hook · คำปิดท้าย · รูปแบบตัดต่อ · รายการคำเสี่ยง · กฎ · เช็กลิสต์ · ข้อตกลง
- รายการคำเสี่ยงใช้รูปแบบเดียวกับ `keywords_banned` ของ TikTok Dashboard (`keyword · category · severity · suggestion · exceptions · scope · match`)
  เริ่มจาก `PQ_STARTER_WORDS_` 19 คำของ Dashboard แล้วเพิ่มอีก 50 คำ ตัวตรวจคำ `js/wordcheck.js` ยกมาจาก `bwFold/bwMatch`

### จุดที่ต่างจาก TikTok Dashboard (ควรแก้ที่ Dashboard ด้วย)

| เรื่อง | Dashboard | ที่นี่ | เหตุผล |
|---|---|---|---|
| ขึ้นบรรทัดใหม่ | ตัดคำ | นับเป็นตัวคั่น | "แพทย์⏎แนะนำ" ในข้อความบนจอหลุดตัวตรวจเงียบ ๆ |
| คำยกเว้นของ "รักษา" | ดูแลรักษา · บำรุงรักษา · รักษาความสะอาด | + เก็บรักษา | "วิธีเก็บรักษา" อยู่บนฉลากเกือบทุกตัว |
| ขอบเขต "รักษา" · "หายขาด" · "เห็นผลทันที" | เฉพาะอาหาร หรือ เฉพาะเครื่องสำอาง | ทั้งหมด | ห้ามทั้งสองหมวด |
| คำยกเว้น "ก่อน-หลัง" · "ขาวใน" | — | + ก่อนหลังจาก · สีขาวใน | วลีทั่วไปที่ไม่ผิด |

