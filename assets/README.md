# รูปภาพของเว็บ

วางไฟล์ตามชื่อด้านล่าง แล้ว commit — หน้าเว็บจะลองโหลดรูปจริงก่อน ถ้าไม่มีไฟล์จะใช้กราฟิกชั่วคราวแทน

|---|---|---|
| `logo.png` | มุมซ้ายบน + การ์ดปกหน้าแรก | สี่เหลี่ยมจัตุรัส 512×512 พื้นโปร่งใสหรือขาว |
| `hero.jpg` | พื้นหลังการ์ดปกหน้าแรก | แนวตั้ง 1080×1350 (4:5) ไม่เกิน 400 KB |
| `products/hayeon.jpg` | รูปสินค้า Hayeon | จัตุรัส 600×600 ไม่เกิน 150 KB |
| `products/plukaw.jpg` | รูปสินค้า พลูคาว พ่อทองชิต | 〃 |
| `products/probiova.jpg` | รูปสินค้า Probiova | 〃 |
| `products/merrycollagen.jpg` | รูปสินค้า MerryCollagen | 〃 |
| `products/venorra.jpg` | รูปสินค้า venorra | 〃 |
